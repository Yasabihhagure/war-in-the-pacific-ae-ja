War in the Pacific: Admiral's Edition - Japanese Localization (Unofficial)
https://github.com/Yasabihhagure/war-in-the-pacific-ae-ja

[English]
This is an unofficial, fan-made Japanese localization. It does not modify
any game files.

- Extract this zip into the game folder (where
  "War in the Pacific Admiral Edition.exe" is), then start the game.
- Required game version: 1.8.11.26a (exe size 5,054,464 bytes).
- Windowed mode is recommended: launch the exe with "-w -skipVideo".
- Files added: ddraw.dll (proxy DLL that draws Japanese text),
  witpae_ja.ini (settings), witpae_ja\ (translations), this file.
  The DLL may be falsely flagged by security software; check the zip's
  SHA-256 against the release notes.
- To uninstall: delete ddraw.dll, witpae_ja.ini, witpae_ja_log.txt,
  witpae_ja_README.txt and the witpae_ja\ folder.

Full instructions: witpae_ja\README.en.md
