# 翻訳の決まり

War in the Pacific: Admiral's Edition の日本語化で、訳文をそろえるための決まりです。用語は [glossary.tsv](glossary.tsv) に従います。

## 1. 壊してはいけないもの

訳文は、ゲームのプログラムがそのまま使います。次のものは、英文と同じ形で残してください。

| もの | 例 | 決まり |
| --- | --- | --- |
| 書式指定 | `%s` `%d` `%.20s` `%2.2d` `%-3d` `%%` | 数も**順番も**変えない。順番を入れ替える仕組みはない |
| 改行 | `\n` | 数と位置を保つ（行の数が画面の配置に関わる） |
| ツールチップの改行 | `~` | 数と位置を保つ |
| 前後の空白 | `" Flak 43"` の先頭の空白 | 残す（表の桁そろえに使われている） |
| キーの案内 | `(E)` `(F)` | そのまま残す |
| 略号 | `TF` `CV` `BB` `DD` `AK` `AP` `CAP` `ASW` `PP` | そのまま残す |
| 区切り線・記号 | `-----` `***` `==>` | そのまま残す |

書式指定の順番を変えられないので、語順は「値が出てくる順」に合わせて工夫します。

- 例: `%s arrives at %s` → `%sが%sに到着`（順番どおり）
- 例: `%d aircraft destroyed at %s` → `%d機を撃破（%s）`（順番を保つため、場所を後ろに回す）

## 2. 文字

- Shift_JIS（CP932）にある文字だけを使う。絵文字、半角カタカナ、機種依存の記号は使わない。
- 数字と英字は半角にする。
- 全角の `～` は使わない（ツールチップの改行 `~` と紛らわしいため）。範囲は「から」「–」などで書く。
- 括弧は、英文が半角 `( )` なら半角のままにする（幅を節約するため）。

## 3. 長さ

画面の枠は英語に合わせて作られています。日本語の1文字は、英字のおよそ2文字分の幅です。

- 目安: 訳文の「全角文字の数」が、英文の文字数の半分から6割を超えないようにする。
- ボタンや表の見出しは、特に短くする（体言止め、略語を使う）。
- 長くなる場合は、意味を落とさずに言い換える。それでも収まらなければ、メモ欄に「長い」と書く。

## 4. 文体

| 種類 | 文体 | 例 |
| --- | --- | --- |
| ボタン・見出し・項目名 | 名詞で短く | `Load Supplies` → `補給物資を積載` |
| ツールチップ・操作の説明 | 「〜する」の常体、または体言止め | `Click to go to base` → `クリックで基地へ移動` |
| 戦闘や作戦の報告 | 常体（である調）、報告らしく簡潔に | `%s is sighted by %s` → `%sが%sに発見される` |
| 確認の質問 | 「〜しますか？」 | `Quit The Game ?` → `ゲームを終了しますか？` |
| シナリオの説明文 | 常体の文章 | |

## 5. 固有名詞

- 文の中に埋め込まれる名前（艦名・地名・部隊名・人名）は `%s` で入るので、訳文では触らない。名前は別の対訳表（`translation/names/`）で訳す。
- 英文に直接書かれた地名や作戦名は、一般的な日本語表記にする（例: `Pearl Harbor` → `真珠湾`、`Guadalcanal` → `ガダルカナル`、Operation "Watchtower" → ウォッチタワー作戦）。
- 日本の航空機・艦艇は、日本側の名称にする（例: Zeke → 零戦、Betty → 一式陸攻。対応は [aircraft_codes.md](aircraft_codes.md)）。
- 連合軍の兵器名は、型式を残してカタカナにする（例: `B-17E Fortress` → `B-17E フォートレス`）。

## 5.1 シナリオの説明文（`translation/scen/`）

シナリオの説明（`SCEN\*.txt`）は、ファイルごと訳して `translation/scen/<同じファイル名>` に置きます（UTF-8、BOM なし、日本語だけ）。道具は `tools/scen.py`。

- 原文の段落・空行・見出し・日付の行の並びは保つ。段落の中の改行位置は自由（ゲームが枠の幅で折り返す）。
- 1行は CP932 で 120 バイト（全角60文字）以内。長い段落は句点のところで改行する。
- 文体は常体（である調）。作戦命令（OPERATIONS ORDER）は命令らしく「〜せよ」「〜すること」。歴史の解説は「〜した」「〜である」。
- 日付は `1942年8月4日` の形にする。
- 地名・人名・部隊名は日本語にする（例: Port Moresby → ポートモレスビー、Kokoda Trail → ココダ道、1st Marine Division → 第1海兵師団、17th Army → 第17軍、Combined Fleet → 連合艦隊）。日本の人名・地名は漢字にする（Yamamoto → 山本五十六、Truk → トラック）。
- 日本側の文書（ファイル名が J で始まるもの）では、日本軍を「我が軍」、連合軍を「敵」と書いてよい（原文の立場に合わせる）。
- 原文の `(Designer's note: ...)` は `（設計者注: …）` とする。
- `~` と `～` は使わない。

## 6. 訳さないもの

次のものは、訳文を空にしておきます（英語のまま表示されます）。

- ファイル名、プログラム内部の名前、デバッグ用の文
- 何に使われるか分からない短い文字列（推測で訳すと画面が壊れることがある）
- 人名だけの文字列
